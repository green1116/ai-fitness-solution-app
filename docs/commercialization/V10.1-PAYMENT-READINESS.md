# V10.1 Payment Integration Readiness

**Version:** `v10.1-payment-readiness-1`  
**Status:** Payment Abstraction Layer (no real gateway, no persistence)  
**Predecessor:** V10 Revenue Foundation Layer (`v10-revenue-foundation`)  
**Successor:** V10.5 Enterprise SaaS Foundation

## Goal

建立支付接入准备层（Payment Integration Readiness），统一支付抽象接口，不调用真实支付、不保存支付信息，与 Revenue Foundation 解耦。

## Domains

| Domain | Runtime | API | Verify |
|--------|---------|-----|--------|
| Payment Gateway | `runPaymentGatewayRuntime` | `GET /api/payment-readiness/gateway/run` | `npm run verify:payment-gateway` |
| Payment Events | `runPaymentEventsRuntime` | `GET /api/payment-readiness/events/run` | `npm run verify:payment-events` |
| Webhook Contract | `runWebhookContractRuntime` | `GET /api/payment-readiness/webhook/run` | `npm run verify:webhook-contract` |
| Subscription Sync | `runSubscriptionSyncRuntime` | `GET /api/payment-readiness/subscription-sync/run` | `npm run verify:subscription-sync` |
| Invoice Settlement | `runInvoiceSettlementRuntime` | `GET /api/payment-readiness/invoice-settlement/run` | `npm run verify:invoice-settlement` |
| Payment Readiness Dashboard | `runPaymentReadinessDashboardRuntime` | `GET /api/payment-readiness/dashboard/run` | `npm run verify:payment-readiness` |

## Module Layout

```
lib/payment-readiness/
  shared/              # runtime harness + version contract
  gateway/             # Stripe / PayPal / Alipay / WeChat / Enterprise Procurement adapters
  events/              # checkout / payment / invoice / subscription events
  webhook/             # event / signature / retry / idempotency schemas
  subscription-sync/   # activate / renew / suspend / cancel / expire
  invoice-settlement/  # pending / paid / overdue / refunded
  dashboard/           # gateway / webhook / subscription / settlement readiness
  evidence.ts          # buildPaymentReadinessEvidence()
  index.ts
```

## Gateway Unified Interface

所有适配器实现统一接口（`readiness-stub` 模式，无真实 API 调用）：

- `createCheckout()`
- `verifyPayment()`
- `refundPayment()`
- `syncSubscription()`

支持网关：Stripe、PayPal、Alipay、WeChat Pay、Enterprise Procurement

## Payment Events

- `checkout.created`
- `payment.succeeded` / `payment.failed`
- `invoice.paid` / `invoice.overdue`
- `subscription.created` / `subscription.renewed` / `subscription.cancelled`

## Boundaries

- **不调用** 真实支付接口
- **不保存** 支付信息
- **不修改** `app/api/pay/`、`lib/payments/` 现有生产支付路径
- **独立于** `lib/revenue-foundation/`（V10 收入描述层）

## Verification

```bash
npx tsc --noEmit
npm run build
npm run verify:payment-gateway
npm run verify:payment-events
npm run verify:webhook-contract
npm run verify:subscription-sync
npm run verify:invoice-settlement

```

Evidence 聚合：`buildPaymentReadinessEvidence()` — 由 `verify:payment-readiness` 覆盖。
