# V13.5 AI Proposal Autopilot Foundation

**Version:** `v13.5-autopilot-1`  
**Status:** Automatic proposal execution runtime (`readiness-stub`)  
**Predecessor:** V13 Real AI Integration Foundation (`v13-ai-integration`)  
**Successor:** V14 Commercial Delivery Platform

## Goal

建立 Proposal Autopilot Runtime，让系统从「工具模式」进入「自动执行模式」。

## Workflow Pipeline

```
Tender Upload → Tender Intelligence → Knowledge Fusion → Proposal Generation
→ Proposal PDF → Plan PDF → Budget PDF → Enterprise ZIP
```

## Domains

| Domain | Runtime | API | Verify |
|--------|---------|-----|--------|
| Autopilot Job | `runAutopilotJobRuntime` | `GET /api/autopilot/job/run` | `npm run verify:autopilot-job` |
| Workflow | `runWorkflowRuntime` | `GET /api/autopilot/workflow/run` | `npm run verify:workflow` |
| Stage Orchestration | `runStageOrchestrationRuntime` | `GET /api/autopilot/stage-orchestration/run` | `npm run verify:stage-orchestration` |
| Retry | `runRetryRuntime` | `GET /api/autopilot/retry/run` | `npm run verify:retry-runtime` |
| Human Review | `runHumanReviewRuntime` | `GET /api/autopilot/human-review/run` | `npm run verify:human-review` |
| Delivery | `runDeliveryRuntime` | `GET /api/autopilot/delivery/run` | `npm run verify:delivery-runtime` |
| Autopilot Audit | `runAutopilotAuditRuntime` | `GET /api/autopilot/audit/run` | `npm run verify:autopilot-audit` |
| Autopilot Dashboard | `runAutopilotDashboardRuntime` | `GET /api/autopilot/dashboard/run` | `npm run verify:autopilot-dashboard` |

## Module Layout

```
lib/autopilot/
  shared/               # runtime harness
  job/                  # Job Id / Type / Status / Lifecycle
  workflow/             # 8-step pipeline definition
  stage-orchestration/  # pending / running / completed / failed / retry
  retry/                # retry policy + fallback route
  human-review/         # auto-approved / manual-review / review-required
  delivery/             # Proposal PDF / Plan PDF / Budget PDF / Enterprise ZIP
  audit/                # stages / runtime / cost / failures / approvals
  dashboard/            # completion / success / retry / review / delivery metrics
  evidence.ts
  index.ts
```

## Boundaries

- **不修改** Proposal Engine、Proposal PDF、Plan Engine、Budget Engine、Enterprise ZIP
- **编排层** 通过公开 Runtime 引用下游模块，不侵入生产引擎
- **独立于** `lib/ai-integration/`、`lib/proposal-generation/`
