# Hidden Internal Modules

The following should not appear in user navigation:

- Quote Engine
- Budget Engine
- Tender Engine
- Artifact Management
- Workflow Engine

These are internal capabilities.

# Navigation Principles

## Principle 1

Show user goals.

Not system functions.

---

## Principle 2

One persona has one primary journey.

---

## Principle 3

Advanced features appear only after user needs them.

---

## Principle 4

AI guides users instead of users searching through menus.
