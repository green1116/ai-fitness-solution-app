## 1. 定位一句话

**AI Fitness Solution = 企业健身空间的「方案 + 预算 + 投标 PDF」垂直工具，不是通用 AI，也不是设计公司或设备商。**

| 维度 | 我们 |
|------|------|
| **品类** | B2B 垂直 SaaS + 项目交付 |
| **买家** | 行政 / HR / 园区运营 / HR 服务商 |
| **买单理由** | 缩短方案周期、统一预算口径、可评审 PDF/Tender |
| **不做什么** | 施工图、施工总包、器械实体销售 |

---

## 2. 竞争格局总览

```
                    交付深度（高）
                         ▲
           设计公司 ─────┼───── 总包/EPC
                         │
     通用 AI ────────────┼────────── 我们
     (ChatGPT 等)        │      (垂直方案+PDF+Tender)
                         │
           设备商方案 ───┼───── Excel 模板
                         │
                         ▼
                    交付深度（低）
        ◄──────── 垂直度（低）    垂直度（高） ────────►
```

**主战场：** 垂直度高、交付深度中等 — **与「设计公司首轮方案」和「Excel+ChatGPT 拼凑」竞争**，不与施工/EPC 正面冲突。

## 3. 对比矩阵

### 3.1 vs 传统设计公司

| 维度 | 设计公司 | AI Fitness Solution |
|------|----------|---------------------|
| **首轮方案周期** | 2–4 周 | **3–5 天** |
| **首轮费用** | ¥3万–8万+ | 订阅 **¥3.6万/年起** 或 Kickstart **¥2万左右** |
| **预算结构** | 常另收费 | **与方案联动** |
| **投标技术标** | 可包但贵、慢 | Professional **Tender Package** |
| **施工图/施工** | ✅ 强项 | ❌ 不做（可协作） |
| **何时选我们** | 仅需概念方案/立项/招采前期 | 需快速内部过会 |
| **何时选设计** | 已立项、要施工图与驻场 | 我们出 brief 后委托 |

**话术：**  
> 「我们用工具 **3 天出可评审方案+预算+PDF**，帮您内部先过会；施工图仍交给贵司信任的设计院，我们减少返工。」

---

### 3.2 vs 健身设备商「免费方案」

| 维度 | 设备商 | AI Fitness Solution |
|------|--------|---------------------|
| **方案动机** | 绑定器械采购 | **中立**，可对接多品牌 |
| **预算客观性** | 倾向自家 SKU | 结构化预算，**便于招采比选** |
| **PDF/投标** | 质量不一 | **标准化 Proposal + Tender** |
| **多网点复制** | 弱 | Professional **多工作区** |
| **何时选我们** | 要先过行政/财务、再比设备 | 设备招标前 |
| **何时选设备商** | 已确定品牌、要一站式供货 | 可作 **渠道转介绍** 伙伴 |

**话术：**  
> 「设备商方案适合 **已定品牌**；我们要帮您在 **定品牌之前** 用中立预算过会，避免被单一品牌绑架。」

---

### 3.3 vs 通用 AI（ChatGPT / 通用 Copilot）

| 维度 | 通用 AI | AI Fitness Solution |
|------|---------|---------------------|
| **行业模板** | 无稳定健身空间结构 | **Plan/Budget/Tender 模板** |
| **输出形态** | 文本为主 | **正式 PDF + 投标包** |
| **企业管控** | 难审计、难复用 | **工作区、里程碑、交付验收** |
| **采购接受度** | IT/法务常阻 | **可对公、合同、发票** |
| **数据隔离** | 不确定 | **按客户工作区隔离** |
| **何时选我们** | 企业采购、招采、多部门协作 | 个人草稿可用通用 AI |
| **何时不贬低通用 AI** | 行政已用 ChatGPT 写邮件 | 「我们把它 **产品化+可交付**」 |

**话术：**  
> 「ChatGPT 能写段落，但过不了 **财务和招采要的 PDF 与投标结构**；我们把健身空间方案 **做成企业可验收的交付物**。」

---

### 3.4 vs Excel / 内部模板

| 维度 | Excel 模板 | AI Fitness Solution |
|------|------------|---------------------|
| **速度** | 依赖个人经验 | **参数化生成** |
| **一致性** | 人多版本乱 | 结构化 Plan/Budget |
| **升级成本** | 模板维护靠人 | 产品迭代统一 |
| **投标** | 需手工拼装 | Tender Package |
| **何时选我们** | 公司要标准化、多项目并行 | 单人偶发可继续 Excel |

## 6. 伙伴而非竞品

| 伙伴类型 | 协作方式 |
|----------|----------|
| **设计公司** | 我们出 brief + 预算 → 对方施工图 |
| **设备商** | 我们中立方案 → 对方报价供货 |
| **装修公司/EPC** | Tender 技术标 → 对方商务标与施工 |
| **HR 平台** | 渠道分销 Professional |

## 7. 禁止对外表述

| 不要说 | 原因 |
|--------|------|
| 「替代设计院/施工方」 | 超出能力，引发纠纷 |
| 「保证 ROI / 保证利用率」 | 模型仅为估算 |
| 「已通过等保三级」 | 除非确有认证 |
| 「无限免费」 | 损害付费试点与 L1/L2 |
