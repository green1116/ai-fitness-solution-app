# 微信外联模板 · WeChat Outreach

**版本：** V9.0-A5 · **执行副本**

---

## 纪律

- 7 天内对同一公司 **≤2 次** 消息  
- 不发「在吗」无正文、不长语音  
- 通过后 **先给价值** 再约 Demo  

---

## 模板 1 — 好友申请（≤30 字）

```
您好，我是做企业健身区方案工具的{名字}，看到贵司{trigger}，想发一份案例参考，感谢通过。
```

---

## 模板 2 — 通过后首条

```
{称呼} 您好～ 我是 AI Fitness Solution 的{名字}。
我们帮企业行政/联办把健身区「方案+预算+PDF」从数周压到数天，中立方案方便过会和招采。
方便的话我可以发 1 页匿名案例，或约 15 分钟线上演示（现场出 PDF）。
您看哪种方便？
```

---

## 模板 3 — 发案例

```
这是匿名案例（1 页）：{链接或文件}
在线示例报告：{官网}/result?planId=attaguy-plan
您有具体人数/面积的话，Demo 可直接用您的数。
```

---

## 模板 4 — 轻催促（5 天无回）

```
{称呼} 打扰，上次案例不知是否有帮助？
若 Q{季度} 有健身区/福利空间项目，欢迎约 15 分钟 Demo，我按贵司参数现场出一版 PDF 供内部参考。
```

---

## 模板 5 — Demo 确认（微信版）

```
{称呼} 已为您预留：
📅 {月日} {时:分}  腾讯会议
链接：{url}
时长 15 分钟，可选准备：人数/面积/预算。
```

---

## 模板 6 — Demo 后（微信）

```
{称呼} 感谢今天演示！PDF 摘要：{链接}
需要的话回复「报价」或「试用」，我这边今天发您。
```

---

## 模板 7 — 报价跟进（微信）

```
{称呼} 报价单昨天已发邮箱，14 天内有效。
有疑问随时语音；若需走试点，回复「试点」我发 Discount 方案说明。
```

---

## 按 ICP 微调一句（插入模板 2）

| ICP | 插入句 |
|-----|--------|
| HR 服务商 | 方便您给下游客户快速出方案+投标 PDF。 |
| 联合办公 | 适合多店标准化健身区方案。 |
| 科技行政 | 适合福利升级/internal 汇报。 |
| 中小企业 | Starter 起步，Often 低于设计公司单次方案费。 |
| 物业 | 适合招采前期技术文件与预算结构。 |
