## Features

### 您可以选择的服务

| 类型 | intent | 说明 | 会后交付 |
|------|--------|------|----------|
| **预约 Demo** | `demo` | 15 分钟线上/现场演示 | 演示摘要 + 示例 PDF |
| **获取报价** | `quote` | 发送 SKU / 项目包报价单 | 14 天有效报价 PDF + SOW 摘要 |
| **申请试用** | `trial` | 开通 14 天 Trial | 试用指南 + 登录说明 |
| **商务合作** | `partner` | 设备商 / 设计所 / HR 渠道 | 合作一页纸 |

### 联系渠道（展示）

| 渠道 | 内容 |
|------|------|
| **表单** | 本页主路径（推荐） |
| **邮箱** | sales@example.com（部署时替换为真实邮箱） |
| **体验链接** | 无需等待：`/plan` 立即自助生成 |

### Demo 您将看到什么（Features 子区块）

1. 输入人数、面积、预算  
2. 生成结构化 **Plan**  
3. 生成联动 **Budget**  
4. 导出 **Proposal PDF**  
5. （可选）介绍 Professional **Tender** 能力

## FAQ

| 问 | 答 |
|----|-----|
| Demo 要准备什么？ | 大概 **人数、面积、预算区间** 即可。 |
| 报价多久收到？ | 通常 **24h 内**（工作日）。 |
| 试用多久开通？ | 审核通过后 **1 个工作日**。 |
| 是否支持电话？ | 表单提交后顾问可约电话/腾讯会议。 |
| 是否提供英文材料？ | Enterprise 个案可安排；标准材料为中文。 |
