# V19.4 Bidder Proposal Composer

**Version:** `v19.4-bidder-proposal-composer-1`  
**Status:** Full proposal orchestration layer (`readiness-stub`)  
**Predecessor:** V19.3 Equipment Selection Engine (`v19.3-equipment-selection`)  
**Successor:** V19.5 Proposal Delivery Packaging

## Goal

将 Bidder Profile、Brand Strategy、Equipment Package、Budget Package、Differentiation Profile 编排进入完整 Proposal。

```
同一 Tender → 四套完整 Proposal → 四种品牌定位 → 四种设备方案 → 四种预算逻辑 → 四种价值主张
```

| Proposal | Brand | Package |
|----------|-------|---------|
| Proposal A | Technogym | Premium Equipment Package |
| Proposal B | Life Fitness | Reliability Equipment Package |
| Proposal C | Matrix | Balanced Equipment Package |
| Proposal D | Shuhua | Value Equipment Package |

**Target:** Proposal Differentiation Score **> 85%**

## Module Layout

```
lib/bidder-proposal-composer/
  shared/
  bridge/                       # context runtime bridge
  proposal-context/             # Tender + Bidder + Brand + Equipment + Budget + Differentiation
  executive-composer/           # Executive Summary / Core Value / Strategic Position
  technical-composer/           # Technical Scope / Equipment Architecture / Deployment Logic
  equipment-plan-composer/      # Equipment Plan / Model Justification / Upgrade Path
  budget-narrative/             # Budget Logic / Cost Justification / Value Justification
  competitive-narrative/        # Competitive / Brand / Service / Delivery Advantage
  proposal-variant/             # Proposal A/B/C/D full variants
  proposal-quality/             # completeness / consistency / alignment checks
  dashboard/                    # Proposal Differentiation Score
  report/
  evidence.ts
  index.ts
```

## Runtime Bridges (read-only)

- `lib/bidder-intelligence/` — bidder profile
- `lib/brand-catalog-intelligence/` — brand intelligence
- `lib/proposal-differentiation/` — differentiation profile
- `lib/equipment-selection/` — equipment package + budget package
