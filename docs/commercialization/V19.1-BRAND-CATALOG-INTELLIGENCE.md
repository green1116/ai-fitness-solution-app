# V19.1 Brand & Catalog Intelligence

**Version:** `v19.1-brand-catalog-intelligence-1`  
**Status:** Brand & equipment knowledge asset layer (`readiness-stub`)  
**Predecessor:** V19 Bidder Intelligence Foundation (`v19-bidder-intelligence`)  
**Successor:** V19.2 Proposal Differentiation Engine

## Goal

将 Bidder Intelligence 从框架升级为数据资产层，扩充品牌知识库与设备知识库，形成真正的 Brand & Catalog Intelligence。

## Domains

| Domain | Runtime | API | Verify |
|--------|---------|-----|--------|
| Brand Intelligence | `runBrandIntelligenceRuntime` | `GET /api/brand-catalog-intelligence/brand-intelligence/run` | `npm run verify:brand-intelligence` |
| Brand Comparison | `runBrandComparisonRuntime` | `GET /api/brand-catalog-intelligence/brand-comparison/run` | `npm run verify:brand-comparison` |

## Module Layout

```
lib/brand-catalog-intelligence/
  shared/
  brand-intelligence/       # Premium / Commercial / Value tier profiles
  brand-comparison/         # Technogym vs Life Fitness, Matrix vs Johnson, etc.
  equipment-intelligence/   # profiles + technical/commercial/maintenance specs
  equipment-matching/       # tender requirements → catalog matching
  budget-mapping/           # low / mid / premium budget profiles
  catalog-coverage/         # brand / category / equipment coverage stats
  dashboard/                # 5-dimension readiness
  report/                   # Brand & Catalog Intelligence Report
  evidence.ts
  index.ts
```

## Brand Intelligence

三级品牌定位：**Premium** / **Commercial** / **Value**

属性：Brand Tier · Market Position · Typical Customer · Competitive Advantages/Disadvantages · Maintenance/Lifecycle Characteristics

品牌库：Technogym · Life Fitness · Matrix · Johnson · Shuhua · Impulse · IntelligentFit

## Equipment Intelligence

五类设备：**Cardio** · **Strength** · **Functional** · **Group Training** · **Recovery**

属性：Equipment Profile · Technical Specifications · Commercial Specifications · Maintenance Specifications

## Brand & Catalog Intelligence Report

`buildBrandCatalogIntelligenceReport()` 输出：

- **Brand Coverage**
- **Equipment Coverage**
- **Budget Coverage**
- **Differentiation Readiness**

## Boundaries

- **不修改** Proposal Engine · Proposal PDF · Budget Engine · Knowledge Base · AI Integration · Commercial Delivery
- **只读桥接** `lib/bidder-intelligence/brand-library` 与 `equipment-catalog` builders
