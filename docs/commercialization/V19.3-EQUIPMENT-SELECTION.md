# V19.3 Equipment Selection Engine

**Version:** `v19.3-equipment-selection-1`  
**Status:** Model-level equipment selection layer (`readiness-stub`)  
**Predecessor:** V19.2 Proposal Differentiation Engine (`v19.2-proposal-differentiation`)  
**Successor:** V19.4 Bidder Proposal Composer

## Goal

建立型号级设备选择引擎，解决「品牌不同但设备型号仍然相似」的问题。

```
同一 Tender → 四套不同设备方案 → 四套不同预算 → 四套不同 Proposal
```

| Bidder Brand | Equipment Package |
|--------------|-------------------|
| Technogym | Premium Equipment Package |
| Life Fitness | Reliability Equipment Package |
| Matrix | Balanced Equipment Package |
| Shuhua | Value Equipment Package |

**Target:** Equipment Differentiation Score **> 80%**

## Module Layout

```
lib/equipment-selection/
  shared/
  bridge/                     # catalog + tender runtime bridge
  equipment-requirement/      # Requirement Profile
  model-selection/            # Preferred / Alternative / Upgrade per route
  equipment-package/          # Premium / Balanced / Value packages
  compatibility/              # category / quantity / requirement coverage
  equipment-differentiation/  # Proposal A/B/C/D model comparison
  budget-package/             # Equipment Package → Budget Package
  dashboard/                  # Equipment Differentiation Score
  report/
  evidence.ts
  index.ts
```

## Runtime Bridges (read-only)

- `lib/brand-catalog-intelligence/` — equipment intelligence, tender requirements, budget mapping
- `lib/bidder-intelligence/` — equipment catalog (via brand-catalog bridge)

## Boundaries

- **不修改** Proposal Engine · Proposal PDF · Budget Engine · Knowledge Base · AI Integration · Commercial Delivery
- **不新增** 品牌或设备数据资产
