# V11.5 AI Model Integration Readiness

**Version:** `v11.5-ai-readiness-1`  
**Status:** Unified AI Runtime Adapter Layer (`readiness-stub`, no real API calls)  
**Predecessor:** V11.2 Proposal PDF Engine (`v11.2-proposal-pdf`)  
**Successor:** V12 Tender Intelligence Foundation

## Goal

建立统一 AI Runtime Adapter Layer，不调用真实 OpenAI/Claude，不产生真实 Token 消耗。

## Module Layout

```
lib/ai-readiness/
  shared/           # runtime harness + readiness-stub mode
  provider/         # OpenAI / Claude / Gemini / DeepSeek / Qwen
  model/            # model id / family / context window / capabilities
  prompt/           # System / User / Proposal / Tender prompts
  completion/       # request / response / finish reason
  token/            # prompt / completion / total tokens
  cost/             # request / proposal / monthly cost estimates
  adapter/          # generateProposal / Summary / Risk / Compliance
  dashboard/        # provider / model / prompt / token / cost readiness
  evidence.ts
  index.ts
```

## AI Adapter Interface

统一 `readiness-stub` 适配器：

- `generateProposal()`
- `generateSummary()`
- `generateRiskAnalysis()`
- `generateComplianceMatrix()`

## Boundaries

- **不调用** 真实 OpenAI、Claude、Gemini 等 API
- **不产生** 真实 Token 消耗或费用
- **不修改** Proposal Engine、Proposal PDF、Plan Engine、Budget Engine
- **独立于** `lib/proposal-generation/`、`lib/proposal-pdf/`
