## Features

### 核心交付物

| 交付物 | 说明 | 典型用途 |
|--------|------|----------|
| **Plan** | 结构化健身空间建设方案 | 内部讨论、设计 brief |
| **Budget** | 与方案联动的预算报告 | 立项、财务审批 |
| **Proposal PDF** | 正式排版 PDF | 管理层汇报、行政审批 |
| **Tender Package** | 投标技术文件包（Professional+） | 招采、比选 |

### 能力卡片（展示用）

| # | 标题 | 描述 |
|---|------|------|
| 1 | **参数化生成** | 输入人数、面积、预算，自动生成分区建议、设备类型与实施节奏。 |
| 2 | **多轮修订** | 按合同约定轮次（如 Kickstart **2 轮**）迭代，避免无限返工。 |
| 3 | **多工作区** | 联合办公、HR 服务商多客户/多网点独立工作区（Professional / Enterprise）。 |
| 4 | **交付里程碑** | Initiated → Proposal Delivered → Completed，签约后可追踪。 |
| 5 | **客户成功** | 采用率、续约与扩展指标（订阅客户季度回顾）。 |

## FAQ

| 问 | 答 |
|----|-----|
| 能替代设计公司吗？ | 不替代施工图与施工；我们负责 **前期方案与招采文件**。 |
| Starter 和 Professional 差别？ | Professional 含 **Tender**、更高额度、**多工作区** 与优先支持。 |
| 输出什么格式？ | 在线结构化内容 + **PDF 导出**；Tender 为投标包（按合同）。 |
| 和 ChatGPT 有何不同？ | 企业可 **验收的 PDF/Tender**、工作区隔离、对公合同与发票。 |
| 设备采购怎么办？ | 方案含预算结构；设备 **中立**，便于多品牌比选。 |
| 实施周期？ | Kickstart 典型 **21 天**；复杂项目单独排期。 |
