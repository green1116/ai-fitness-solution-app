# V11.2 Proposal PDF Engine

**Version:** `v11.2-proposal-pdf-1`  
**Status:** Proposal Package → formal bid PDF (decoupled from Plan/Budget PDF)  
**Predecessor:** V11 AI Proposal Generation Foundation (`v11-proposal-generation`)  
**Successor:** V11.5 AI Model Integration Readiness

## Goal

将 Proposal Package 输出为正式投标文档 PDF，独立于 Plan PDF / Budget PDF 引擎。

## Domains

| Domain | Runtime | API | Verify |
|--------|---------|-----|--------|
| Proposal Cover | `runProposalCoverRuntime` | `GET /api/proposal-pdf/cover/run` | `npm run verify:proposal-cover` |
| Proposal Sections | `runProposalSectionRuntime` | `GET /api/proposal-pdf/sections/run` | `npm run verify:proposal-section` |
| Proposal TOC | `runProposalTocRuntime` | `GET /api/proposal-pdf/toc/run` | `npm run verify:proposal-toc` |
| PDF Assembly | `runProposalPdfAssemblyRuntime` | `GET /api/proposal-pdf/assembly/run` | `npm run verify:proposal-assembly` |
| PDF Dashboard | `runProposalPdfDashboardRuntime` | `GET /api/proposal-pdf/dashboard/run` | `npm run verify:proposal-pdf-dashboard` |

PDF 渲染：`GET /api/proposal-pdf/render` → `proposal.pdf` 字节流

## Module Layout

```
lib/proposal-pdf/
  shared/           # runtime harness + metadata (branding / watermark / REQSIG)
  cover/            # Project Name / Customer / Version / Date
  sections/         # 6 chapters from Proposal Generation
  toc/              # Table Of Contents + Section Index
  assembly/         # Aggregate + renderProposalPdf()
  dashboard/        # page count / completeness / render readiness
  evidence.ts
  index.ts
```

## PDF Structure

```
Cover → TOC → Executive Summary → Technical → Implementation → Risk → Delivery → Compliance
```

## Metadata

- **Branding:** `AI Fitness Solution — Proposal PDF Engine`
- **Version:** `V11.2 Proposal Delivery`
- **Watermark:** optional `CONFIDENTIAL` overlay
- **REQSIG:** independent proposal pack signature (`computeProposalReqsig`)

## Boundaries

- **不修改** Plan Engine、Budget Engine、Enterprise ZIP、Tender Runtime
- **不共用** `renderPlanPdf` / `budgetRender` 渲染管线（仅复用 `loadChineseFont`）
- **输入来自** `lib/proposal-generation/` Proposal Assembly
