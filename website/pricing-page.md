## FAQ

| 问 | 答 |
|----|-----|
| 支持月付吗？ | MVP 以 **年付或项目包** 为主；月付个案联系销售。 |
| 可以在线付款吗？ | **不可以**；对公转账 + 增值税发票。 |
| 试点折扣多少？ | Starter 最高 **5 折**、Professional **7 折**，须签案例/推荐条款。 |
| 定金可退吗？ | 可抵扣合同款；未签约退款规则见定金协议。 |
| 续费价格？ | 试点价仅首期；续约按标准价或书面协商。 |
| 如何获取正式报价单？ | [联系销售](/contact?intent=quote)，24h 内发送 PDF 报价包。 |
