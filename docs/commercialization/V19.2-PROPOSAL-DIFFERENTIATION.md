# V19.2 Proposal Differentiation Engine

**Version:** `v19.2-proposal-differentiation-1`  
**Status:** Proposal differentiation layer (`readiness-stub`)  
**Predecessor:** V19.1 Brand & Catalog Intelligence (`v19.1-brand-catalog-intelligence`)  
**Successor:** V19.3 Bidder Proposal Composer

## Goal

建立真正的投标方案差异化引擎。同一 Tender，不同投标方生成显著差异化的投标方案：

| Bidder Brand | Proposal |
|--------------|----------|
| Technogym | Proposal A |
| Life Fitness | Proposal B |
| Matrix | Proposal C |
| Shuhua | Proposal D |

```
Tender + Bidder Profile + Brand Library + Equipment Catalog + Knowledge Base
  → Differentiated Proposal Strategy
```

## Module Layout

```
lib/proposal-differentiation/
  shared/
  bridge/                   # tender context runtime bridge
  brand-strategy/           # premium / balanced / value strategies
  value-proposition/        # core value / differentiation / position
  competitive-advantage/    # brand / service / delivery / support matrix
  equipment-strategy/       # preferred / alternative / upgrade path
  budget-strategy/          # premium / mid / value budget strategies
  differentiation-profile/  # aggregated Proposal Differentiation Profile
  dashboard/                # differentiation score + 4 dimensions
  report/                   # Proposal Differentiation Report
  evidence.ts
  index.ts
```

## Runtime Bridges (read-only)

- `lib/bidder-intelligence/` — bidder profile, supplier capability
- `lib/brand-catalog-intelligence/` — brand intelligence, equipment intelligence, budget mapping
- `lib/knowledge-base/proposal/` — proposal knowledge assets

## Boundaries

- **不修改** Proposal Engine · Proposal PDF · Budget Engine · Knowledge Base · AI Integration · Commercial Delivery
- **不新增** 品牌或设备数据资产（复用 V19 / V19.1）
