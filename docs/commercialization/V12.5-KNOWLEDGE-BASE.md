# V12.5 Knowledge Base Foundation

**Version:** `v12.5-knowledge-base-1`  
**Status:** System-level knowledge asset layer (`readiness-stub`)  
**Predecessor:** V12 Tender Intelligence Foundation (`v12-tender-intelligence`)  
**Successor:** V13 Real AI Integration Foundation

## Goal

建立系统级知识资产层（Knowledge Asset Layer）。不接真实向量数据库、不接真实 Embedding、不接真实 AI。

## Module Layout

```
lib/knowledge-base/
  shared/              # runtime harness
  project/             # Project Type / Scale / Budget / Equipment
  equipment/           # Category / Profile / Deployment / Maintenance
  proposal/            # Executive / Technical / Implementation / Compliance templates
  risk/                # Category / Pattern / Mitigation
  compliance/          # Requirement / Compliance / Evidence patterns
  catalog/             # Unified catalog (Project / Equipment / Proposal / Risk / Compliance)
  search/              # Keyword / Category / Profile search (in-memory stub)
  assembly/            # Knowledge Asset Package
  dashboard/           # Completeness / Coverage / Search readiness
  evidence.ts
  index.ts
```

## Knowledge Asset Package

```
Project + Equipment + Proposal + Risk + Compliance + Catalog + Search → Knowledge Asset Package
```

## Boundaries

- **不接** 向量数据库、Embedding、真实 AI
- **不修改** Proposal Engine、Proposal PDF、Tender Intelligence、Plan/Budget/ZIP
- **独立于** `lib/tender-intelligence/`、`lib/proposal-generation/`
