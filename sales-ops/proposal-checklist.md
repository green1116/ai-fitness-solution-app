## 发报价前

| ☐ | 项 |
|---|-----|
| ☐ | 需求确认表已归档 |
| ☐ | SKU + 项目包选定（Kickstart / Tender Ready / Multi-Site / 仅订阅） |
| ☐ | `quotation-template.md` 已填写 |
| ☐ | 折扣 ≤ 上限（Starter 5折 / Pro 7折）；超上限已书面批注 |
| ☐ | 报价有效期 **14 天** |
| ☐ | SOW 修订轮次（默认 2 轮）已写明 |
| ☐ | 付款条款：首付 50% / 验收 50% |
| ☐ | CRM：`Stage`=Proposal，`ARR`=`quoted_amount` |
| ☐ | `proposal_sent_date` 已记录 |
