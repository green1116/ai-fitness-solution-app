# V10.5 Enterprise SaaS Foundation

**Version:** `v10.5-enterprise-saas-1`  
**Status:** Multi-tenant organization model (read-only runtime)  
**Predecessor:** V10.1 Payment Integration Readiness (`v10.1-payment-readiness`)  
**Successor:** V11 AI Proposal Generation Foundation

## Goal

建立企业级 SaaS 多租户基础层，不接真实认证/RBAC，不修改 Plan Engine、Budget Engine、Enterprise ZIP、Tender Runtime。

## Domains

| Domain | Runtime | API | Verify |
|--------|---------|-----|--------|
| Tenant | `runTenantRuntime` | `GET /api/enterprise-saas/tenant/run` | `npm run verify:tenant` |
| Workspace | `runWorkspaceRuntime` | `GET /api/enterprise-saas/workspace/run` | `npm run verify:workspace` |
| User | `runUserRuntime` | `GET /api/enterprise-saas/user/run` | `npm run verify:user` |
| Role | `runRoleRuntime` | `GET /api/enterprise-saas/role/run` | `npm run verify:role` |
| Permission | `runPermissionRuntime` | `GET /api/enterprise-saas/permission/run` | `npm run verify:permission` |
| Seat | `runSeatRuntime` | `GET /api/enterprise-saas/seat/run` | `npm run verify:seat` |

| Enterprise Dashboard | `runEnterpriseDashboardRuntime` | `GET /api/enterprise-saas/dashboard/run` | `npm run verify:enterprise-dashboard` |

## Module Layout

```
lib/enterprise-saas/
  shared/           # runtime harness + version contract
  tenant/           # Tenant / Status / Tier / Lifecycle (Trial/Pro/Enterprise)
  workspace/        # Workspace / Settings / Summary / Lifecycle
  user/             # User Profile / Status / Membership
  role/             # Owner / Admin / Manager / Member / Viewer
  permission/       # Plan / Budget / Tender / Billing / Admin Access
  seat/             # Licensed / Active / Available Seats
  usage/            # Projects / Plans / Budgets / ZIP / Tender Uploads
  dashboard/        # Aggregated enterprise summaries
  evidence.ts
  index.ts
```

## Organization Model

```
Tenant → Workspace → User + Role → Permission → Seat + Usage → Dashboard
```

## Boundaries

- **不接** 真实认证系统
- **不接** 真实 RBAC 执行
- **不修改** Plan/Budget/ZIP/Tender 生产引擎
- **独立于** `lib/revenue-foundation/`、`lib/payment-readiness/`

## Verification

```bash
npx tsc --noEmit
npm run build
npm run verify:tenant
npm run verify:workspace
npm run verify:user
npm run verify:role
npm run verify:permission
npm run verify:seat
npm run verify:usage
npm run verify:enterprise-dashboard
```

Evidence 聚合：`buildEnterpriseSaasEvidence()` — 由 `verify:enterprise-dashboard` 覆盖。
