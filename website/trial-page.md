## Features

### 试用权益（明确上限）

| 权益项 | 试用额度 |
|--------|----------|
| 周期 | **14 天** |
| 工作区 | 1 |
| 用户 | 最多 3 |
| Plan 生成 | ≤10 次 |
| Budget 生成 | ≤5 次 |
| PDF 导出 | ≤10 次 |
| Tender Package | **不包含** |
| Onboarding | ≤2 小时（远程） |

### 试用包含的服务

| # | 标题 | 描述 |
|---|------|------|
| 1 | **自助生成** | 与正式产品相同的 Plan / Budget / PDF 流程 |
| 2 | **第 7 天 check-in** | 使用情况回顾与最佳实践 |
| 3 | **到期前 7 天** | 商业方案沟通（报价 / 试点 / 定金） |
| 4 | **升级路径** | 一键升级 Starter / Professional，权益与数据按合同迁移 |

### 三种路径对比（简表）

| 模式 | 收费 | 周期 | 适合 |
|------|------|------|------|
| **Free Trial** | 免费 | 14 天 | 预算未批、需内部验证 |
| **Discount Pilot** | 付费折扣 | 3 个月 | 已立项、愿付定金/首付 |
| **Joint Case Study** | 接近标价 | 6 个月 | 联合办公 / HR 服务商（#3 目标） |

**内链：** 付费试点详情见 sales-kit [pilot-program.md](../sales-kit/pilot-program.md)

## FAQ

| 问 | 答 |
|----|-----|
| 试用真的免费吗？ | 是，**不绑卡、不自动扣费**。 |
| 到期会怎样？ | 权益只读锁定；续签后恢复。数据保留按合同。 |
| 能否无限生成？ | 否，见上方额度表，防止滥用。 |
| 能否开 Tender？ | 试用 **不含** Tender；需 Professional。 |
| 试用和 Demo 区别？ | Demo 15 分钟由顾问带教；试用 **14 天自助**。 |
| 如何升级付费？ | 联系销售或提交申请，发送 [报价](/pricing)。 |
| HR 服务商可以申请吗？ | 可以，但可能引导至 **付费试点** 而非长期免费。 |
