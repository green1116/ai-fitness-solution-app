## 1. 试点目标

| 里程碑 | 试点目的 | 推荐模式 |

## 2. 三种试点模式

### 2.1 Free Pilot（免费试点）

| 维度 | 内容 |
|------|------|
| **定义** | 限功能、限次数的 14 天试用，换反馈与使用数据 |
| **收费** | 否（或 ¥0 象征合同） |
| **周期** | **14 天**（对齐 V8.4 Trial） |
| **适合客户** | 科技公司行政（有项目、预算未批）；**不建议** HR 服务商/联合办公长期免费 |
| **权益上限** | 1 workspace · 3 users · Plan≤10 · Budget≤5 · PDF≤10 · **无 Tender** |

**优势：** 低门槛、快速 Evaluation、竞争卡位  

**风险与缓解：**

| 风险 | 缓解 |
|------|------|
| 用完即走 | 协议：仅 1 个项目；到期锁定权益 |
| 售前成本过高 | 仅 SQL≥60 开放；onboarding ≤2h |
| 被当免费出图工具 | 不提供代做；到期前 7 天必须进入 Commercial |

**适用阶段：** 第 1 家之前缓冲；**第 1 家优先 Discount 直接付费**

---

### 2.2 Discount Pilot（折扣试点）— 第 1 家首选

| 维度 | 内容 |
|------|------|
| **定义** | 付费 + 显著折扣，换案例授权与推荐 |
| **收费** | 是（对公 + 发票） |
| **周期** | **3 个月**（可含首年订阅） |
| **折扣上限** | Starter 年费 **5 折**；项目包协商 |
| **适合客户** | 80–150 人科技/中小企业；预算已立项 |

**推荐打包（参考）：**

| 项目 | 参考价 |
|------|--------|
| Starter 年费（5 折） | ¥30,000 |
| Kickstart 项目包 | ¥20,000 |
| **合计** | **约 ¥50,000** |

**客户需交换：**

- 案例授权（**匿名最低** / 署名优先）  
- 试点结束后 **1 条转介绍** 或 50 字推荐语  
- 试点价 **仅首期**；续约按标准价或协商

**风险与缓解：**

| 风险 | 缓解 |
|------|------|
| 锚定低价 | 合同写明试点价仅首期 |
| 交付超期 | SOW 21 天 + 2 轮修订上限 |
| 不付尾款 | 50/50 付款；验收后尾款 |

---

### 2.3 Joint Case Study Pilot（联合案例试点）— 第 3 家

| 维度 | 内容 |
|------|------|
| **定义** | 接近标价或轻微折扣，深度共创可发布案例 |
| **收费** | 是 |
| **周期** | **6 个月** |
| **适合客户** | 联合办公 3–5 店、HR 服务商业务线 |
| **SKU** | **Professional** |

**客户需交换：**

- 联合案例访谈（交付后 45 天内）  
- Logo / 数据授权（可谈判匿名）  
- 至少 **1 次** 联合对外内容（公众号/官网/活动）

**折扣上限：** Professional **7 折** 内

| 转介绍意向 | 记录 | ≥1 条线索 | ≥2 条线索 |
| 续费意向（试点末） | N/A | ≥7/10 | ≥8/10 |

## 4. 试点 → 正式订阅路径

```
Trial / Pilot 开始
    → 第 7 天 check-in（usage 回顾）
    → 到期前 14 天：Commercial 报价
    → 到期前 7 天：续约/升级或锁定只读
    → Won：标准年费或升级 Professional
```

## 5. 合同附录要点（粘贴用）

1. **试点期限：** 自 __年__月__日起 __ 天/月。  
2. **权益范围：** 以 [pricing-sheet.md](pricing-sheet.md) SKU __ 及附件 SOW 为准。  
3. **折扣：** 仅适用于 **首期/首年**；续费按标准价或双方书面确认。  
4. **案例授权：** 客户授予 __匿名/署名__ 案例使用权；客户可在发布前审阅稿件。  
5. **推荐义务：** 试点满意后，客户愿提供 __1__ 条转介绍或书面推荐语。  
6. **数据与保密：** 双方项目数据仅用于交付，未经同意不对外披露。  
7. **终止：** 任一方提前 14 日书面通知；已交付部分按 SOW 结算。

## 6. 决策树（销售用）

```
预算已批？
  ├─ 是 → Discount Pilot 或 标准价
  └─ 否 → SQL≥60？
           ├─ 是 → Free Trial 14 天 + 到期前报价
           └─ 否 →  nurture，不开放 Free

多网点 / HR 服务商？
  ├─ 是 → Joint Case Study（#3 目标）
  └─ 否 → Discount Starter（#1 目标）
```
